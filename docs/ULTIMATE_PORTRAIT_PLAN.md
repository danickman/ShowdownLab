## Efficient art budget and contract

Target **20 generation calls total** (one canonical + one seven-pose sheet per fighter), rather than 80 isolated generations. For the pilot, evaluate a combined canonical + seven-pose production board: if extraction and anatomy quality pass, use **10 boards total**, each yielding an independent canonical and seven separate reference assets. Do not sacrifice identity or scale consistency to reduce calls. Repair failed poses together in one targeted repair board where possible; no blind retries, maximum two automated corrective calls per fighter before manual defect review. A further correction requires a specific observed defect and a changed pose/constraint, never a blind retry. Dragon needed one such explicit three-to-four-foot correction.

Generation prompts, untouched sources and manifests live under `tools/art-spike/<fighter>/ultimate/`. Final runtime assets live under `v3/assets/authored/<fighter>/ultimate/`. One anatomy scale across each pack, registered foot/body/weapon points, transparent padding, complete equipment. Canonical must be clearly distinct from Evolved at phone battle size, not merely more gold or a larger sprite. Seven poses: idle, move, attack, guard, signature, hit, defeat. Source boards are references, not multi-frame animation; runtime adds controlled pose motion.

Identity/equipment/pose clarity minimum 8.5/10, zero critical anatomy/equipment/crop defects; scores are editorial, never fabricated by an automated processor. Ultimate silhouette and capability readability must be judged beside Base/Evolved. Save rejected sources with reasons; replace only failed cells.
